> **Flame-grilling malformed, broken LLM JSON into standard valid JSON at lightning speed.**

`JsonRepair.NET` is an ultra-fast, zero-allocation C# 13 / .NET 10 library crafted by the **Bifteki Crew**. It repairs raw, truncated, or non-standard JSON generated by Large Language Models (LLMs) and legacy APIs into strictly conforming JSON parseable by `System.Text.Json`.

---

## 🥩 Why Bifteki JsonRepair.NET?

LLMs (OpenAI, DeepSeek, Anthropic, Ollama) frequently produce "burnt" or broken JSON outputs that crash standard parsers with `JsonException`:
- ❌ **Markdown Fences**: ` ```json { ... } ``` `
- ❌ **Single Quotes**: `{'user': 'Bifteki Chef'}`
- ❌ **Unquoted Keys**: `{name: "Alice"}`
- ❌ **Python / JS Literals**: `None` $\rightarrow$ `null`, `True` $\rightarrow$ `true`, `undefined` $\rightarrow$ `null`
- ❌ **Trailing Commas**: `[1, 2, 3,]`
- ❌ **Unclosed Truncated JSON**: `{"items": [1, 2`

`JsonRepair.NET` uses a single-pass `ref struct` state machine over `ReadOnlySpan<char>` to repair all these syntax errors with **zero heap allocations** on the warm path!

## 🚀 Quick Start

### 1. Installation
```bash
dotnet add package JsonRepair
```

### 2. Basic Usage
```csharp
using JsonRepair;

string malformedLlmJson = """
```json
{
    crew: 'Bifteki Team',
    flame_grilled: True,
    secret_ingredient: None,
    items: ['Patty', 'Garlic',],
```
""";

// Repair into valid standard JSON
string repaired = JsonRepairEngine.Repair(malformedLlmJson);
Console.WriteLine(repaired);
// Output: {"crew":"Bifteki Team","flame_grilled":true,"secret_ingredient":null,"items":["Patty","Garlic"]}

// Exception-free Direct Parsing into JsonDocument
if (JsonRepairEngine.TryParse(malformedLlmJson, out JsonDocument? doc))
{
    using (doc)
    {
        Console.WriteLine($"Crew: {doc.RootElement.GetProperty("crew").GetString()}");
    }
}
```
